Fonts embedded in the admin price-list PDF (src/lib/price-list/pdf.ts) so
Turkish/extended-Latin product names render correctly and the PDF matches the
site's typography (Inter + Playfair Display, as used via next/font).

Inter and Playfair Display are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Static TTFs taken from the Google Fonts builds
published as @expo-google-fonts/inter@0.4.2 and
@expo-google-fonts/playfair-display@0.4.2.
